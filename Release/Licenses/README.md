# Third-party notices bundled with Astro

The adjacent files preserve the license texts supplied with the dependencies used for the macOS app. `Release/Package.resolved` records the Xcode dependency revisions; the two local Swift packages are under `Vendor/`.

- `Kokoro.txt`: mlalma/kokoro-ios.
- `MisakiSwift.txt`: mlalma/MisakiSwift.
- `MLXSwift.txt`, `MLX.txt`, `MLX-C.txt`, `fmt.txt`, `nlohmann-json.txt`, `Metal-cpp.txt`: ml-explore/mlx-swift and its included source components.
- `MLXUtilsLibrary.txt`: mlalma/MLXUtilsLibrary.
- `SwiftNumerics.txt`: apple/swift-numerics.
- `WebRTC.txt`: stasel/WebRTC distribution and the WebRTC project notice supplied with it.
- `ZIPFoundation.txt`: weichsel/ZIPFoundation.
- `ThinkingOrbsKit.txt`, `BorderBeamKit.txt`: the local packages of those names.

Keep these notices with redistributed copies and update them when dependencies change. These dependency notices do not grant a license to Astro's own code or artwork. Provider services and model files downloaded later have their own terms; they are not covered by this collection.
